# Meal Planner Demo

Prototipo móvil con SvelteKit 2, Svelte 5, TypeScript e IndexedDB (Dexie).

```bash
npm install
npm run dev
```

Datos de prueba locales, plan semanal, recetario, compra agregada y ausencias. Sin backend ni sincronización. Los datos se guardan por navegador; se pueden restablecer desde Ajustes.

Para publicar: GitHub → Settings → Pages → Source: GitHub Actions. El workflow publica cada cambio en `main`.
